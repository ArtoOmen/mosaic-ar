# Живая мозаика — WebAR

Человек сканирует QR, в браузере открывается страница, он наводит камеру на мозаику, и птицы оживают. Приложение ставить не нужно, работает в Safari (iOS) и Chrome (Android).

## Что происходит, когда камера видит мозаику

- Мозаику распознаёт [MindAR](https://github.com/hiukim/mind-ar-js) по «отпечатку» `assets/targets.mind`. Поверх неё точно ложится оживлённая копия.
- **Птицы на мозаике** вертят головами, взмахивают крыльями, качают хвостами. Моргают, а зрачки следят за телефоном. Дерево, цветы и ягоды покачиваются. Всё это делает шейдер, который локально деформирует изображение. Бетонные рамы между панелями остаются неподвижными.
- **3D-птицы из смальты** по очереди вылетают из нарисованных птиц, облетают мозаику в объёме и возвращаются обратно. За ними сыплются кусочки плитки.
- Если коснуться птицы на экране, она вылетает.
- Звук синтезируется прямо в браузере: щебет, трели, уханье совы. Аудиофайлов нет.
- Без камеры (или на компьютере) доступен демо-режим с параллаксом от мыши или гироскопа.

## Структура

```
index.html            приложение (UI + стили)
qr.html               стенд: фото мозаики + QR + печать таблички A4
js/main.js            сценарий: AR-сессия, демо, UI, тексты ru/en
js/mural.js           шейдер «живой мозаики»
js/flock.js           3D-птицы и осколки смальты
js/audio.js           синтез птичьих голосов
js/rig.js             разметка: глаза, «кости», гнёзда (пиксели mural.jpg)
assets/mural.jpg      мозаика (930×1001), она же мишень для трекинга
assets/targets.mind   скомпилированная мишень MindAR
assets/mask.png       маска: R — где можно деформировать, G — где рисовать наложение
tools/compile.html    компилятор новой мишени прямо в браузере
vendor/               three.js 0.160.1, MindAR 1.2.5, qrcode-generator (локальные копии)
```

## Запуск и публикация

Камера на телефоне работает только по **https**. Подойдёт любой статический хостинг: GitHub Pages, Netlify, Vercel, Cloudflare Pages или свой сервер. Сборка не нужна, достаточно выложить папку как есть.

Локально (демо и проверка на компьютере):

```bash
python3 -m http.server 8080 --directory mosaic-ar
```

После публикации откройте `https://ваш-адрес/qr.html`. QR-код строится автоматически под текущий адрес, там же кнопка печати таблички. Для другого адреса можно указать `qr.html?url=https://...`.

## Параметры ссылки

| Параметр | Что делает |
|---|---|
| `?mode=demo` | сразу открыть демо без камеры |
| `?lang=en` | английский интерфейс |
| `?cf=0.001&beta=100` | сглаживание трекинга (One Euro filter). Меньше `cf` — меньше дрожи, больше `beta` — меньше задержка |
| `?res=1280` | желаемая ширина видео с камеры |
| `?debug` | наложение полупрозрачное, чтобы проверить совпадение с мозаикой |

## Когда мозаика появится на стене

Сейчас мишень — это кадр из визуализации. Для настоящей стены:

1. Сфотографируйте мозаику строго фронтально при ровном свете и обрежьте по раме.
2. Замените `assets/mural.jpg` и соберите новый `assets/targets.mind` через `tools/compile.html`.
3. Если пропорции или рисунок поменялись, поправьте координаты в `js/rig.js` (глаза, кости, гнёзда в пикселях изображения) и пересоберите `assets/mask.png`.
