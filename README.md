# Живая мозаика — WebAR

Человек сканирует QR, в браузере открывается страница, он наводит камеру на мозаику, и птицы оживают. Приложение ставить не нужно, работает в Safari (iOS) и Chrome (Android).

Сайт: https://artoomen.github.io/mosaic-ar/

## Что происходит, когда камера видит мозаику

- Мозаику распознаёт [MindAR](https://github.com/hiukim/mind-ar-js) по «отпечаткам» в `assets/targets.mind`. Сайт знает несколько мозаик и сам определяет, какую из них видит камера. Поверх неё точно ложится оживлённая копия.
- **Птицы на мозаике** вертят головами, взмахивают крыльями, качают хвостами. Моргают, а зрачки следят за телефоном. Дерево, цветы и ягоды покачиваются. Всё это делает шейдер, который локально деформирует изображение. Бетонные рамы между панелями остаются неподвижными.
- **3D-птицы из смальты** по очереди вылетают из нарисованных птиц, облетают мозаику в объёме и возвращаются обратно. Если коснуться птицы на экране, она вылетает.
- Звук синтезируется прямо в браузере: щебет, трели, уханье совы.
- Без камеры (или на компьютере) доступен демо-режим. Кнопка ⇄ переключает мозаики.

## Ракурсы

Проверено на смоделированной камере телефона:

- **с нуля** мозаика узнаётся под углом до 55–65° сбоку, 35° снизу и по диагонали (35° сбоку + 30° снизу);
- **если мозаика уже поймана**, трекинг держится при обходе сбоку почти до 75°;
- две мозаики в одном стиле ни разу не перепутались.

Лучше всего работает, когда эталонное фото снято строго фронтально при ровном свете.

## Структура

```
index.html                 приложение; на компьютере это стенд: большая картинка + QR
qr.html                    табличка A4 с QR для печати
assets/targets.json        список мозаик (порядок = порядок в targets.mind)
assets/targets.mind        скомпилированные мишени MindAR для всех мозаик
assets/t/<id>/mural.jpg    мозаика, фронтально (она же мишень трекинга)
assets/t/<id>/mask.png     маска: R — где можно деформировать, G — где рисовать наложение, B — сама мозаика
assets/t/<id>/rig.json     разметка: глаза, «кости» (что и как двигается), гнёзда 3D-птиц
assets/t/<id>/photo.jpg    картинка для стенда на компьютере
js/main.js                 сценарий: AR-сессия, демо, UI, тексты ru/en
js/mural.js                шейдер «живой мозаики»
js/flock.js                3D-птицы и осколки смальты
js/audio.js                синтез птичьих голосов
js/rig.js                  палитра и загрузка списка мозаик
tools/prepare_target.py    автоматическая подготовка новой мозаики
tools/compile.html         сборка targets.mind в браузере
vendor/                    three.js 0.160.1, MindAR 1.2.5, qrcode-generator, es-module-shims
```

## Как добавить новую мозаику

1. Подготовить картинку (нужны Python и `pip install numpy opencv-python-headless`):

   ```bash
   python3 tools/prepare_target.py фото.jpg --id birds-c --title "Мозаика 3"
   ```

   Скрипт сам найдёт мозаику на фото, вырежет её, построит маску, найдёт глаза птиц и расставит повороты голов, моргание и точки вылета. Результат можно проверить глазами в `assets/t/birds-c/rig_preview.jpg`.

   Если фото снято под углом, передайте 4 угла рамы (левый верхний, правый верхний, правый нижний, левый нижний) и реальное соотношение ширины к высоте, и мозаика будет распрямлена:

   ```bash
   python3 tools/prepare_target.py сбоку.jpg --id birds-c --corners 73,27,1424,212,1442,1533,70,1497 --aspect 0.92
   ```

2. Открыть `tools/compile.html` на локальном сервере (см. ниже), нажать «Собрать все картинки» и положить скачанный `targets.mind` в `assets/`.
3. По желанию добавить в `rig.json` «кости» для хвостов, крыльев и веток (`sway`, `flap`, `bob`). Формат описан в `js/rig.js`.
4. Закоммитить и запушить: GitHub Pages обновит сайт за минуту.

## Запуск и публикация

Камера на телефоне работает только по **https**. Сейчас сайт живёт на GitHub Pages, но подойдёт любой статический хостинг: сборка не нужна.

Локально (демо и проверка на компьютере):

```bash
python3 -m http.server 8080 --directory mosaic-ar
```

## Параметры ссылки

| Параметр | Что делает |
|---|---|
| `?mode=demo` | сразу открыть демо без камеры (`&t=birds-b` — конкретную мозаику) |
| `?t=birds-b` | какую мозаику показать на стенде |
| `?lang=en` | английский интерфейс |
| `?cf=0.001&beta=100` | сглаживание трекинга (One Euro filter). Меньше `cf` — меньше дрожи, больше `beta` — меньше задержка |
| `?res=1280` | желаемая ширина видео с камеры |
| `?debug` | наложение полупрозрачное, чтобы проверить совпадение с мозаикой |
